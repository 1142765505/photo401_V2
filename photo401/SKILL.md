# Photo401

## 输入与输出

- 每次只需用户提供一张待编辑底图，称为「图片1」。附件或明确指定的本地文件均可。
- 人物和工位参考已内置，不需要用户每次重复上传。先读 [人物与工位参考](references/person-and-seat.md)，再查看其中最适合当前角度的图片。
- 衣服是可选参数：`使用photo401skill 衣服2`、`使用photo401 衣服2` 或 `$photo401 衣服2` 均表示选择衣服2。每次仅按本次请求选择，未指定时使用默认衣服，不沿用上次编号。具体文件定位和款式见 [衣服选择](references/clothing.md)。
- 输出一张以图片1为基础、只在本人对应工位新增本人的合成照片，称为「图片2」。原文件保留，默认保存到当前工作目录的 `output/Photo401/`，命名为 `<输入文件名>_Photo401_图片2.png`；重名时递增版本号。
- 不将任何一张参考后照当成输出底图，也不以另一张前照替代本次图片1。不自动编辑整个文件夹。

## 选择衣服

- 未指定衣服，或明确说「默认衣服」：使用 `assets/person-close.png` 中本人的棕色翻领长袖上衣；不把衣服1当作默认，也不因衣服文件夹存在而自动换衣。
- 指定「衣服N」（如「衣服2」）：按 [衣服选择](references/clothing.md) 找到编号图片，查看该图片，并把它作为本次图像编辑的衣服参考传入。选中的衣服覆盖人物参考图中的上衣，身份、体型、工位及其他未指定衣着保持原规则。
- 编号不存在、文件无法读取或同号有多个候选时，列出实际可用编号或冲突文件并询问必要信息，不擅自换成默认衣服。用户只要求更新技能时，不自动生成示例照片。

## 定位本人及工位

1. 查看图片1与参考图；本地图片使用 `view_image`，不能只凭文件名推断内容。
2. 后照红框内的人物是用户本人；框外其他人只作为场景定位参考。红框用于指认，不是输出的一部分，也不是精确抠图边界。
3. 根据桌面、显示器、隔断交点及相邻纸箱的空间关系，找到同一个真实工位。参考中的归一化位置只用于理解那张参考图，不能照搬到新底图。不要因为某张参考图中人物在画面中央，就把人物放进新底图中央。
4. 用最相近的视角参考人物，必要时再配一张近景参考身份。保持参考人物的短发、侧脸轮廓和体型；参考中有眼镜时保留相应特征，不凭空美化或更换身份。上衣按本次衣服选择执行；未指定衣服时使用默认棕色翻领长袖上衣，不能被另一张人物参考图的衣着覆盖。
5. 姿态默认自然坐在原有座椅上，朝向本人显示器，手臂自然处于键鼠附近。优先利用图片1现有的椅子和桌面，不复制参考图的家具。身体与桌面、椅背、显示器之间保持合理遮挡。
6. 工位局部被遮挡时，只呈现视角中合理可见的身体部分。若工位完全在画外、无法从参考对应工位，或目标工位已被他人占用，说明具体问题并仅询问必要的定位信息，不删除他人、不凭空扩图。图片1已经有本人时不再增加第二个本人。

## 执行编辑

使用内置 `image_gen` 图像编辑工具；如当前环境有 `imagegen` 技能，遵循其内置工具流程。不要用代码绘图或简单矩形粘贴冒充人物合成。

- 参考顺序为：本次图片1在先，人物身份参考在后，再按需要加入工位参考，若指定衣服则最后加入选中的衣服图。将各自用途及实际序号写清楚；默认衣服不需要另传衣服图。通常使用底图、身份图、可选工位图和一张选中衣服图，不把整个衣服文件夹全部传入。
- 当所有图片都有本地路径时，先查看，再用 `referenced_image_paths` 传入绝对路径。若底图只有聊天附件而没有路径，使用工具支持的近期图片引用方式，并确保它同时包含底图和所有选定参考；不能假定工具看到了未传入的图片。两种引用方式不能混用。若引用机制无法覆盖必要图片，才请用户重新附上缺失图片。
- 提示词要具体写出本次工位在底图中的位置和定位依据，而非只说「我的工位」。按下方模板填入实际观察。
- 内置工具不可用时如实说明；不要把提示词当成已生成的图片，不私自改用付费 API。仅在用户明确选择 CLI/API 备选后遵循 imagegen 的备选流程。

```text
Use case: compositing / identity-preserve
Asset type: 实验室照片局部人物合成
Primary request: 编辑所提供的第一张图（图片1），只在指定的本人空工位新增参考中的同一个人，形成图片2。
Input images: [逐张列明实际序号和用途：唯一底图、本人身份、可选工位及可选衣服参考。指定衣服时，明确最后一张衣服参考只负责衣着，不负责身份或场景]。人物参考照片中红框指认的才是目标人物。
Target seat in Image 1: [写出在本次底图中的位置、显示器/隔断/纸箱等关系及座椅位置]。
Subject: 精确参考框中本人的发型、脸部轮廓、眼镜（如参考中有）和体型，不使用框外任何人的脸。本人仅出现一次，自然坐在该工位原有座椅上，面朝该工位显示器，按当前视角呈现合理的侧面或背侧面。
Clothing: [未指定时写明“默认棕色翻领长袖上衣”；指定时写明衣服编号、衣服参考的实际序号及观察到的颜色、领型、长短袖、纽扣、口袋、面料纹理和可见内搭]。指定衣服优先于身份/工位参考图中的旧上衣。衣服自然贴合本人体型和坐姿，保留合理褶皱与遮挡；不改变脸、发型、体型或其他人的衣服。
Lighting and perspective: 匹配图片1的透视、人物尺度、光照方向、色温、清晰度、噪点及压缩质感；新增身体与现有桌面、椅背及显示器正确遮挡，接触阴影自然。
Constraints: 以最小局部修改完成，仅允许新增穿本次指定或默认衣服的本人及融合所需的局部遮挡和阴影。保持图片1的构图、视角、画幅、整体亮度和所有无关区域；保持其他人物、纸箱、屏幕内容、桌椅、窗户、地面、标牌和已有文字。禁止重新生成整个实验室，禁止搬入参考图背景，禁止挪动工位、重绘他人或增加第二把椅子。不要把参考红框、箭头或标注带入输出。衣服商品图仅参考前景主展示衣服，不复制截图界面、价格、广告文字、商标宣传图、衣架、展示手或背景中的其他衣服；不主动新增文字或图形。
```

## 核对与交付

生成后查看图片2，并对照图片1检查：是否同一个人、是否同一个工位、是否仅出现一次、是否穿本次指定衣服（未指定则为默认衣服）、身体比例和遮挡是否自然、无关人物及背景是否意外改变、是否带入红框或衣服商品截图的界面/广告。不能仅以工具执行成功作为质量通过。

如有明显问题，只针对该问题重试，并继续使用原始图片1作为底图。默认最多修正两次；仍不满足则保留候选并说明具体不足，避免无限生成。

「仅新增本人」是编辑目标，生成工具可能改动局部细节或输出尺寸；未做逐像素检查不能宣称背景逐像素一致。若发现明显非目标改动或尺寸变化，修正或明确说明，不将其默认为合格。

按工具实际返回路径取得生成文件，复制最终版本到输出目录；不要虚构保存路径。交付时展示图片2并给出文件链接，简短说明它是合成图及任何未解决问题。此技能只制作图片，不提交打卡、上传外部系统或发送给别人。
