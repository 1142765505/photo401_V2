# 衣服选择

## 调用规则

- 附上图片1并输入 `使用photo401skill 衣服2`：使用编号2对应的衣服。
- `使用photo401 衣服1`、`$photo401 衣服3` 采用同样的规则；允许「衣服 2」中间有空格。
- `使用photo401skill` 或 `使用photo401skill 默认衣服`：使用人物近景参考 `assets/person-close.png` 中的默认棕色翻领长袖上衣。默认衣服与衣服1不是同一项。
- 衣服选择只对本次请求有效，不记住上一次的编号。用户另外明确描述本次衣着时按其要求；若与编号存在无法兼容的冲突，再简短澄清。

## 查找文件

1. 用户明确指定衣服文件夹时使用该文件夹；否则若当前工作目录下有 `衣服/`，以该文件夹为准；不存在时才使用技能内置的 `assets/衣服/`。
2. 按文件名而非排序位置选择。`衣服2` 对应 `2.jpg`，也可对应同号的 `2.jpeg`、`2.png`、`2.webp` 或名为 `衣服2` 的上述格式图片。新增 `4.jpg` 后即可用 `衣服4`，不必修改编号表。不要把商品截图的“3/6”页码、价格或文件排序当成衣服编号。
3. 在所用文件夹里找到唯一的对应图片。若同号存在多个文件则询问选择，不按扩展名擅自决定；若指定编号缺失则列出该文件夹实际可用编号，不静默回退到内置副本或默认衣服。
4. 编辑前查看选中的原始图片，再把其绝对路径作为衣服参考传给图像编辑工具。不要仅凭下方文字描述代替实际参考图。

款式表用于快速理解；文件夹实际内容及本次查看的图片优先。只提取最前方主展示衣服的颜色、款式与纹理，忽略后排的其他颜色、商品宣传文字、价格、手机界面、衣架及展示手。衣服图不作为人物身份参考，也不替换图片1的背景。

选择衣服时，新增本人穿选中衣服。脸、发型、眼镜、体型继续按人物参考；工位继续按图片1和工位参考。不要因为人物参考中穿棕色上衣，就覆盖用户已经选定的灰色或军绿色衣服。
